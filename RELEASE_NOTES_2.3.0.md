# Motion Database 2.3.0

Motion Database 2.3.0 adds queryable and interactive Markdown table embeds,
column-level display formats, and a custom query layout for Obsidian Bases
1.10+. It also improves database table editing, mobile controls, row actions,
and SQL validation and transaction handling.

The release bundle contains `main.js`, `manifest.json`, and `styles.css`.
